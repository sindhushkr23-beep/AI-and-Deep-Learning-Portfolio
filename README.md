# 🚗 Car Price Predictor (ML Portfolio Project)

This repository contains a Machine Learning project built to demonstrate core concepts unlocked during **Milestone 1 (AI Foundations)** and **Milestone 2 (Machine Learning)**. It predicts the resale value of used cars based on historical data attributes.

## 🛠️ Tech Stack & Architecture
*   **Language:** Python
*   **Libraries:** Pandas, NumPy, Scikit-Learn
*   **Algorithm:** Random Forest Regressor

## 📊 File Guide
*   `car_price_predictor.py`: Core machine learning pipeline.
*   `car_data.csv`: Source historical car data.
*   `requirements.txt`: Necessary libraries to run this machine learning script.
